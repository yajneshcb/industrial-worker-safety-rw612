# NXP RW612 CMSIS Device Support

This directory contains device-level CMSIS header files and system startup initialization files for the **NXP RW612** (`RW612ETA2I`) Cortex-M33 microcontroller.

When linking against an installed NXP MCUXpresso SDK:
- `fsl_device_registers.h`
- `RW612.h`
- `RW612_features.h`
- `system_RW612.h` / `system_RW612.c`
- Linker scripts (`RW612_flash.ld` / `RW612_ram.ld`)
- Startup code (`startup_rw612.S`)
